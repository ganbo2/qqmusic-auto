# QQ音乐自动点击（QQMusicAuto）

一个**无需 root** 的 Android 工具：在你设定的**北京时间**、**多个时间点**，自动点击 QQ音乐 里的「立即提现」按钮。
通过系统 **无障碍服务（AccessibilityService）** 实现，控件按**文字**定位，适配任意分辨率手机。

> 时间以**网络校时（NTP）**为准，不依赖可能不准的手机系统时钟；到点**零等待立即点击**。
> 本项目由 WorkBuddy 生成，所有操作仅在本地执行，不上传任何数据。

## 一、怎么拿到 APK（本机无法编译，走云端构建）

本工程**已经帮你 `git init` 并提交好了**（分支 `main`，共 21 个文件）。你只需把代码推到 GitHub，Actions 会自动编译出 APK。整个过程免费、约 3~6 分钟。

### 第 1 步：在 GitHub 网页新建一个空仓库
1. 打开 https://github.com/new
2. Repository name 填 `qqmusic-auto`（随意）
3. **务必保持空仓库**：不要勾选 "Add a README file" / "Add .gitignore" / "Choose a license"
4. 点 **Create repository**

### 第 2 步：把本地代码推上去
新建完成后，页面会显示仓库地址。在本地 **Git Bash**（或终端）进入本工程目录，执行：

```bash
git remote add origin https://github.com/你的用户名/qqmusic-auto.git
git push -u origin main
```

> **关于登录认证（重要）**：GitHub 已不支持用「账号密码」登录 git 命令行。
> - **最简单（推荐）**：用 **GitHub Desktop**（图形界面）。打开它 → File → Add local repository → 选本工程目录 → 点 **Publish repository**，登录一次 GitHub 即可推送，全程不用记命令。
> - **用命令行 HTTPS**：密码处要填 **Personal Access Token（PAT）**：GitHub → 右上角头像 → Settings → Developer settings → Personal access tokens → 生成一个勾选 `repo` 权限的 token；推送时用户名填账号、密码处粘贴这个 token。

### 第 3 步：等 Actions 自动打包并下载 APK
1. 推送成功后，打开你的仓库 → 顶部 **Actions** 标签。
2. 会看到工作流 **Build QQMusicAuto APK** 自动开始跑（黄色圆点 → 约几分钟后变绿色对勾）。
3. 点进这次运行 → 最下方 **Artifacts** 区域 → 下载 **`qqmusic-auto-debug`**。
4. 解压下载的 zip，里面就是 **`app-debug.apk`**。

> 说明：workflow 用 `gradle-version: 8.2` 在云端自动下载 Gradle 编译，**不需要本机有 JDK / Android SDK / Gradle / gradle wrapper**。

## 二、安装与授权

1. 安装 `app-debug.apk`（允许「未知来源」）。
2. 打开 App → 点 **「1. 开启无障碍服务」** → 在系统列表找到 **「QQ音乐自动点击」** 并开启。
3. **无需「精确闹钟」权限**：本工具使用系统「闹钟」通道（setAlarmClock），既准时又不挑机型（没有该权限入口的国产 ROM 也能用）。
4. **建议**：设置 → 应用 → QQ音乐自动点击 → 电池 → 设为「不受限制 / 不优化」。
5. 确保 **QQ音乐已登录**。

## 三、使用流程（重要）

1. 在 App 主界面用 **「＋ 添加点击时间」** 选北京时间（可加多个，可删除）。
2. 点 **「2. 保存并启用定时任务」**：App 会先联网校时，再按最新偏差排程。
3. 顶部状态栏会显示**当前网络北京时间**及与手机时钟的偏差。
4. **每次到点前，请手动打开 QQ音乐 里含「立即提现」的页面**，时间一到 App 会立即点击（无需自动开 App）。
5. 想先验证？点 **「立即测试一次」**，现在就点一次（请确保页面已打开）。

## 四、关于「精准北京时间」

- App 在**启动、保存、开机**时通过 NTP（优先 `time.google.com` / `cn.ntp.org.cn` / `ntp.aliyun.com`，失败再用 HTTP 兜底）获取真实时间，并计算与手机系统时钟的偏差。
- 排程时：把你填的「北京时间」先换算成真实 UTC 毫秒，再用偏差换算回系统时钟去 `setAlarmClock`（系统闹钟通道），
  **即使手机系统时间被手动改过 / 不准，闹钟也会在正确的真实北京时间响起**。
- 该通道**不受 Doze 合批、也不要求「精确闹钟」权限**，到点准时并会自动点亮屏幕——专门解决某些国产 ROM（如努比亚）"没有精确闹钟入口 + 不精确闹钟被提前合批"导致定时提前响的问题。
- 为保险起见，到点后会**再加 1 秒安全裕度**再点击，确保不会早于 QQ音乐 服务器开窗（提现窗口整日开放，晚 1 秒无影响）。
- 偏差会保存在本机，离线时退化为系统时间（状态栏会提示「未校时」）。

---

## 五、关于「立即点击 / 5 毫秒内」

- 默认不启动 QQ音乐、不等待：闹钟一响直接广播给无障碍服务，**下一帧立即查找并点击「立即提现」**，没有人为延时。
- 点击动作本身（`performAction`）是同步的、近乎瞬时；端到端的时延主要是系统调度与无障碍节点遍历（通常几十毫秒级）。
  **操作系统层面无法向硬件一样保证「精确 5ms」**，但本工具已做到「到点即点、零人为延时」；若页面在你打开时早已渲染好，首次轮询即可命中。

> 若你勾选了「（可选）时间到自动打开 QQ音乐」，则会先启动 App 再点击（此时会有 App 启动耗时）。

## 六、已知限制

- 需你**手动把含「立即提现」的页面保持在前台**；到点时屏幕会自动点亮，但请**不要给手机上锁屏密码/图案**——锁屏后手势会点不到 QQ音乐（让屏幕自然熄灭即可）。也不要把 QQ音乐 切到后台。
- Android 10+ 对后台有限制，建议加电池白名单；努比亚等国产 ROM 把本 App 和 QQ音乐 都设为电池「无限制」。
- QQ音乐 改版导致按钮文字变化时，改一下 App 里的「目标按钮文字」即可。
