# QQ音乐自动点击（QQMusicAuto）

一个**无需 root** 的 Android 工具：在你设定的**北京时间**、**多个时间点**，自动点击 QQ音乐 里的「立即提现」按钮。
通过系统 **无障碍服务（AccessibilityService）** 实现，控件按**文字**定位，适配任意分辨率手机。

> 时间以**网络校时（NTP）**为准，不依赖可能不准的手机系统时钟；到点**零等待立即点击**。
> 本项目由 WorkBuddy 生成，所有操作仅在本地执行，不上传任何数据。

---

## 一、怎么拿到 APK（本机无法编译，走云端构建）

本工程没有本地 Android SDK，推荐用 **GitHub Actions 免费自动打包**：

1. 在 GitHub 新建仓库（如 `qqmusic-auto`）。
2. 把本目录推上去：
   ```bash
   git init
   git add .
   git commit -m "init qqmusic-auto"
   git remote add origin https://github.com/你的用户名/qqmusic-auto.git
   git push -u origin main
   ```
3. 打开仓库 → **Actions** → 找到 `Build QQMusicAuto APK` → 等绿色对勾。
4. 进入该次运行的 **Artifacts**，下载 `qqmusic-auto-debug`，解压得 `app-debug.apk`。

> 备选：用 Android Studio 打开本工程直接 `Build > Build Bundle(s)/APK(s)`。
> 若 Actions 报「缺少 gradle wrapper」，在本地/Android Studio 执行一次 `gradle wrapper` 再推送。

---

## 二、安装与授权

1. 安装 `app-debug.apk`（允许「未知来源」）。
2. 打开 App → 点 **「1. 开启无障碍服务」** → 在系统列表找到 **「QQ音乐自动点击」** 并开启。
3. 若系统弹出「精确闹钟」权限，请允许（Android 12+ 必需）。
4. **建议**：设置 → 应用 → QQ音乐自动点击 → 电池 → 设为「不受限制 / 不优化」。
5. 确保 **QQ音乐已登录**。

---

## 三、使用流程（重要）

1. 在 App 主界面用 **「＋ 添加点击时间」** 选北京时间（可加多个，可删除）。
2. 点 **「2. 保存并启用定时任务」**：App 会先联网校时，再按最新偏差排程。
3. 顶部状态栏会显示**当前网络北京时间**及与手机时钟的偏差。
4. **每次到点前，请手动打开 QQ音乐 里含「立即提现」的页面**，时间一到 App 会立即点击（无需自动开 App）。
5. 想先验证？点 **「立即测试一次」**，现在就点一次（请确保页面已打开）。

---

## 四、关于「精准北京时间」

- App 在**启动、保存、开机**时通过 NTP（优先 `time.google.com` / `cn.ntp.org.cn` / `ntp.aliyun.com`，失败再用 HTTP 兜底）获取真实时间，并计算与手机系统时钟的偏差。
- 排程时：把你填的「北京时间」先换算成真实 UTC 毫秒，再用偏差换算回系统时钟去 `setExact`，
  **即使手机系统时间被手动改过 / 不准，闹钟也会在正确的真实北京时间响起**。
- 偏差会保存在本机，离线时退化为系统时间（状态栏会提示「未校时」）。

---

## 五、关于「立即点击 / 5 毫秒内」

- 默认不启动 QQ音乐、不等待：闹钟一响直接广播给无障碍服务，**下一帧立即查找并点击「立即提现」**，没有人为延时。
- 点击动作本身（`performAction`）是同步的、近乎瞬时；端到端的时延主要是系统调度与无障碍节点遍历（通常几十毫秒级）。
  **操作系统层面无法向硬件一样保证「精确 5ms」**，但本工具已做到「到点即点、零人为延时」；若页面在你打开时早已渲染好，首次轮询即可命中。

> 若你勾选了「（可选）时间到自动打开 QQ音乐」，则会先启动 App 再点击（此时会有 App 启动耗时）。

---

## 六、已知限制

- 需你**手动把含「立即提现」的页面保持在前台**；若手机锁屏/QQ音乐被切到后台，节点可能不可见，导致点不到（可勾选自动打开 App 缓解）。
- Android 10+ 对后台有限制，建议加电池白名单。
- QQ音乐 改版导致按钮文字变化时，改一下 App 里的「目标按钮文字」即可。

---

不收集、不上传任何信息；仅申请网络权限用于校时，时间配置与偏差存于本机 SharedPreferences。
